Data format: CSV files, zipped

Description: Internationally collected, standardized dataset on glacier state and change (length, area, volume, mass) based on in-situ measurements, remote sensing, and reconstructions.

Spatial coverage: Global

Temporal coverage: 1127-2026 AD
