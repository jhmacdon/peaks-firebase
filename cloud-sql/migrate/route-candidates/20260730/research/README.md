# Research-only route artifacts

Never pass files in this folder to the route importer.

- Files named `draft`, `alt`, or `v2` are earlier or incomplete candidates.
- `gunung-butak-kraton-osm.geojson` diverges from the standard summit approach
  by about 545 m in private reference checks.
- `hikurangi-te-ara-ki-hikurangi-osm.geojson` uses a parallel shortcut instead
  of the current mapped route and diverges by up to 57.9 m.
- The five Colorado files without `osm` in their names use an older candidate
  format that lacks the full retrieval-source record now required.
- Cerro Copiapó, Mauna Kea, the Sapitwa skyline draft, and She Devil still use
  a placeholder trailhead ID.
- `tajumulco-osm.geojson` starts at the older Llano de la Guardia trailhead.
  The top-level San Sebastián candidate is the safer current route.

These files preserve prior research without presenting it as publishable work.
Rebuild a clean top-level candidate before either peak can advance.
