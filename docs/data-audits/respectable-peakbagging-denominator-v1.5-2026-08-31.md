## What remains

The four new source rosters contain 678 memberships across 648 peaks. Of those,
121 have prior source review and 527 need new identity review. No list may go
live until each identity, credited destination cover, safe route, and credited
route cover passes review. DoBIH members `2711`, `2713`, `2735`, and `2877`
keep their firing-range blocks.

PR #180 is ready, not merged. It has no import or production write path. The
42-of-83 figure therefore describes the ready source stack only. It does not
show production coverage and does not prove a worldwide share.

The JSON amendment pins the v1.4 file hashes, PR #180 head, source fixture hash,
four roster hashes, deterministic list IDs, and all changed counts.
